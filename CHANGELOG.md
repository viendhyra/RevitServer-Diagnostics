# Changelog

## 3.0.0 - 2026-08-25

- Удалено ошибочное правило, считавшее `clr.dll 4.8.4795.0` безусловной неисправностью.
- Добавлен независимый от версии Windows поиск применимых обновлений через Windows Update Agent.
- Добавлены безопасные режимы ремонта IIS/Revit Server и Rapid-Fail = 20.
- Добавлены проверенная загрузка ProcDump, резервная копия и сценарий отката.
- Добавлены отдельные защитные ключи для обновлений, .NET Framework 4.8.1 и Dynamic IP Restrictions.
- Диагностика разделена на модули и покрыта Pester-тестами в Windows PowerShell 5.1.
